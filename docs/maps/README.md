# Player maps

Maps of the twelve levels of Eye of the Beholder (DOS), drawn from the game's own level files by `tools/maps/` (`make maps`). They show every wall, door, switch, lock, trap, message, item and monster, so they are full of spoilers.

| File | What |
|---|---|
| `dungeon.pdf` | How the twelve levels connect: every stair, hole and portal, and where the stone items that work the portals lie |
| `level-01.pdf` to `level-12.pdf` | One level each: the plan with numbered notes, and a second page when the notes need it |
| `eye-of-the-beholder-maps.pdf` | All thirteen in one file |

Cells are written `(x,y)`, both from 0 at the top left, north up, as the game numbers them. The copy read is the fan patch "1.9". How each mark is read from the data is in `tools/maps/README.md`.
