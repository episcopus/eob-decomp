## Summary

Round 3 (main 7c3b967): review fails on three must-fix items. The round 2 fixes hold, and the bytes support what the comments say about the mechanics: the caller's request build and failure print (07C8:0245 to 0258, 0265 to 0283, read on the disassembly), the MemAlloc flag 20h return (`MK_FP(seg + 1, 0)`, E19BC.C), the 4B03h parameter block at ES:BX = DGROUP:818Ah ([H] DOS EXEC function 03 layout), the entry call at segment:0 through 818Eh, the MemRealloc arguments and the failure path's pop order. What a reader cannot take from this file is the mechanism and the mouse flag. The header calls the unit VROOMM, but VROOMM is the INT 3Fh runtime trap, and this unit loads named driver overlays on request. The comments on g814A say clearing it switches the handler off, but the code says zero lets the handler run, so clearing it turns it on. Both must-fix sentences come from that one reversed reading, and the E1A72.ASM comment that started it is in another unit.

Still placeholders, for lack of evidence: the overlay-loader words DGROUP:818Ah to 8194h (raw addresses in the code), the entry arguments 27h and 1A16h (1A16h is the segment of WaitFrames, E1A16.C; what the entry does with them is not established), the pad byte at 1C00:0001 (a lone 0 byte [H]), and the name g814A (see the note).

Round 3 fixes (commit 657a135). The unit header no longer calls the loader VROOMM: it names the graphics driver overlays and DOS 4B03h, cites WHITEPAPER 2.5 and 2.3, and says the INT 3Fh hook is 1A72:0006 (installed at 07C8:008F). The g814A polarity is corrected in the EXTRN comment and in the 1C00:0055 comment: non-zero skips the handler body (E1A72.ASM:254-255) and makes HidePointer/ShowPointer do nothing (E1BBE.ASM:89-90, 178), so the loader's clear turns the handler and the pointer on; the wrong E1A72.ASM:236 reading and the "E07A9.C reads zero the other way" sentence are gone. The 1C00:0055 comment now says the loader reads the name through DS (its own request segment, [bp+8]) and never reads word +2, and that the three `pop cx` leave CX = the overlay segment, which is MemRealloc's pointer segment. Both long comment blocks are reflowed; no line of the file runs past 100 characters. g814A is renamed gMouseDisabled with `make rename` (re/renames.toml, re/globals.toml); E07A9.C, E14EF.C, E1A72.ASM and E1BBE.ASM get the name when this branch merges. The E1A72.ASM:44 and :236 comment fix is routed to the e1a72 unit. make match: 2 of 2, 235 bytes; make readability UNIT=e1c00: 0 findings.
