## Summary

The unit reads as a set of graphics routines, and the names of the four registered functions are backed by their callers: DirectionFromPoints and Distance take packed map cells and return a direction and a distance, and TranslateImage is the icon translator for the mouse cursor. The source's own description of the data tables and the register writes is where it goes wrong: several table users are named after the wrong path (EGA where the code is MCGA or CGA), the 7FBC table is 16 bytes not 9, one table formula is wrong, the source/destination pair in two comments is swapped, and the header still names gSoundVolume, which is gPartyCell now. None of these changes a byte. The unit is not understandable without those fixes. The placeholders that remain are honest (FindNeighbour is "Purpose unknown", with its evidence). Nothing else needs the human except the registry: 15 of the 18 PROCs have no entry in re/symbols.toml, so review-pass cannot stamp them, and that is the escalation above.
